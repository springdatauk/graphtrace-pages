Import a project

Create a project, choose Import, then select CSV, TSV or modern Excel (.xlsx) files. Put unique column headings in row 1. Import your People, Tasks and Dependencies sheets, matching the columns for each role. IDs must be stable and unique. A dependent task points to the prerequisite it needs first.

Replace a spreadsheet

Choose Import and import the updated sheet into the same role. Saved mappings are reused when the headings still match. Review additions, removals and changed fields in Changes. An invalid import leaves the existing project unchanged.

Resolve ambiguous names

When GraphTrace flags unmatched references, choose Review matches above the workspace and select the correct person or task by ID. The app remembers your choice. For missing people or tasks, import their sheet or fix the source file. Unresolved references are excluded from the graph and can make impact results incomplete.

Excel limitations

Use .xlsx rather than .xls. Recalculate and save formula results in Excel before importing. GraphTrace does not run formulas or macros, read password-protected workbooks, or reproduce Excel number formats. Numeric IDs are imported as their stored values; store IDs as text to preserve leading zeroes. Limits: 10,000 data rows and 100 columns per sheet, 30 MB per input file, 60 MB expanded workbook and 30 worksheets. Graph views display up to 200 matching items; impact queries use the full project.

Move between devices

Use Project actions → Export project, then transfer the .sheetgraph file with AirDrop or Files. Open it in GraphTrace on the other device. It imports as a separate project. Automatic cloud synchronisation and live collaboration are not included.

Subscriptions and restore

One editable project and the sample workflow are free. GraphTrace Plus enables additional projects. The purchase screen shows your local price, renewal period and any eligible trial before purchase. Open GraphTrace Plus to restore purchases. Manage or cancel through Apple account subscriptions. Existing projects and exports remain accessible when Plus ends. Apple manages billing and refund requests.

Delete data

Use Project actions → Delete project. Keep an export first if needed. Delete exported files and backups separately. No project content is stored on our servers.
